# Support Copilot

A GenAI support copilot that triages tickets, answers questions from help docs with citations, and escalates to a human when needed.

**Status:** in progress (Nov 2026)

## Planned features
- `/classify`: ticket triage into validated JSON (topic, urgency, summary)
- `/answer`: answers from help docs, with citations
- `/agent`: LangGraph agent that searches docs, looks up orders, or escalates
